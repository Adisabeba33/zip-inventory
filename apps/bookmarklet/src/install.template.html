Strain Reader

A bookmark that reads the dispensary menu already open in your browser and gives you the strain names, grouped by package size, one per line.

It runs entirely inside the page you are looking at. It makes no network request, uploads nothing and stores nothing. The only thing that leaves is what you choose to put on your own clipboard.

Install on a computer

  1. Show the bookmarks bar — Ctrl+Shift+B, or ⌘+Shift+B on a Mac.
  2. Drag this button onto it:

Read strains

Dragging is the only way that works — clicking it here does nothing, because there is no menu on this page to read.

Install on a phone

iOS Safari and Firefox on Android can both do this, it is just fiddlier:

  1. Copy the code from the box below.
  2. Bookmark any page — this one will do.
  3. Edit that bookmark, rename it Read strains, and replace its address with what you copied.

Using it

  1. Open a dispensary's flower menu.
  2. Scroll to the bottom. Most menus load as you scroll, and it can only read what the page has actually loaded.
  3. Tap the Read strains bookmark.
  4. Copy one package size, or all of them.

Highlighting some text first reads only that. Highlight nothing and it reads the whole page.

What it does with what it finds

  • Keeps flower only — pre-rolls, vapes, edibles, concentrates and accessories are dropped.
  • Sorts into the four standard sizes: 1/8, 1/4, 1/2 and 1 oz. Anything else is set aside rather than forced into the nearest one.
  • Strips producer, price, potency and packaging words, and never rewrites the cultivar itself.
  • Shows one row per strain per size, with a count when the same strain is listed by more than one producer.
  • Lists every line it did not use, with the reason. Nothing disappears quietly.
It will not get everything. Menus differ, and some are drawn in ways plain text cannot describe. Treat the result as a first pass to check, not as a finished list — that is exactly why the Set aside section exists.
